HiTOP-SR Module Builder

Choose the HiTOP-SR scales you need and download a questionnaire carrying only those items — a Word form to print, a Qualtrics import file, or a REDCap data dictionary.

Everything runs in your own browser. To do that the page fetches R from webr.r-wasm.org, the hitop package from jmgirard.r-universe.dev, and the further R packages it needs from repo.r-wasm.org.

Word item numbering

The instrument's own numbers are what this page's Qualtrics and REDCap exports use for their field names, so a paper response can be typed into a project built here without translating its number.

Word item order

A shuffled form is not scored as it stands. Responses come back in the order the form printed, which is not the instrument's own; put those columns into the original HiTOP-SR order before scoring, or the scale scores come out wrong and nothing warns you.

The Qualtrics and REDCap files are never shuffled: there an item number names a collected data column.

Qualtrics and REDCap naming

These name what the import creates in the target system. None of them reaches the Word form, and none changes the items, their wording, or their response options. Each box starts at the package's own default; empty one and that default is used again.
