HiTOP-SR Module Builder

Choose the HiTOP-SR scales you need and download a questionnaire carrying only those items — a Word form to print, a Qualtrics import file, or a REDCap data dictionary.

Everything runs in your own browser. To do that the page fetches R from webr.r-wasm.org, the hitop package from jmgirard.r-universe.dev, which hands the file itself off to r2.ropensci.org, and the further R packages it needs from repo.r-wasm.org.

Paper size
Item numbering

The instrument's own numbers are what this page's Qualtrics and REDCap exports use for their field names, so a paper response can be typed into a project built here without translating its number.

Item order

A shuffled form is not scored as it stands. Responses come back in the order the form printed, which is not the instrument's own; put those columns into the original HiTOP-SR order before scoring, or the scale scores come out wrong and nothing warns you.

Shuffling reaches this form only. The Qualtrics and REDCap files are never shuffled: there an item number names a collected data column.

Block and question naming

These name what the import creates in Qualtrics. Neither changes the items, their wording, or their response options. Each box starts at the package's own default; empty one and that default is used again.

Form name and required items

These name what the import creates in REDCap and how it asks for answers. Neither changes the items, their wording, or their response options. The box starts at the package's own default; empty it and that default is used again.

Two files are saved, and both matter. Beside the questionnaire, this page saves a small .json file naming the scales you chose — and, on a shuffled Word form, the order the items were printed in.

Keep it with the responses you collect. The hitop package reads it back with read_module(), so scoring needs neither a retyped scale list nor a printed order reconstructed by hand.

The button builds both files in this browser and saves them. It turns on once at least one scale is ticked.
