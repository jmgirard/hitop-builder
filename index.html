Word settings
Paper size
Item numbering

The Qualtrics and REDCap exports on this page use the instrument's own numbers for their field names. With those numbers on the paper form, you can type a paper response into a project built here without translating its number.

Item order

A shuffled form takes one more step to score. If you enter the data in the printed order, its columns are in that order. Then, in R, read the module file with read_module() and pass that module to score_hitopsr() with layout = "printed". Columns in the HiTOP-SR's own order take the default layout. The wrong layout gives wrong scale scores and no error.

Only the Word form is shuffled. In the Qualtrics file and the REDCap dictionary, an item number names a data column.

Qualtrics settings
Block and question naming

These name what the import creates in Qualtrics. Neither changes the items, their wording, or their response options. Each box starts at the package's own default. If you empty a box, the page uses that default again.

REDCap settings
Form name and required items

These name what the import creates in REDCap and how it asks for answers. Neither changes the items, their wording, or their response options. The box starts at the package's own default. If you empty it, the page uses that default again.

The download is one zip file. It holds the questionnaire, a module file that lists your scales, and a README.txt. Keep the module file with the responses. The hitop package reads it with read_module() when you score them.

For REDCap, upload the inner -upload.zip file as it is.

The download is one module file that lists your scales. The Online form shows the items itself, so there is no questionnaire to build. Keep the module file with the responses. After the save, the next step is the study link. Two saves that each skip some scales share a file name, so rename one if you keep both.

Technical details

The page fetches R from webr.r-wasm.org. It fetches the hitop package from jmgirard.r-universe.dev, which hands the file itself to r2.ropensci.org. It fetches the other R packages it needs from repo.r-wasm.org.
