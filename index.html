HiTOP-SR Module Builder

Tick the scales you want and download a ready-to-field questionnaire containing only those items, in Word, Qualtrics, or REDCap format.

This page builds blank questionnaires. It does not score anything. It never asks for, receives, or transmits anyone's responses. To work, the page downloads R itself from webr.r-wasm.org and the hitop package from jmgirard.r-universe.dev; both then run inside your own browser, and every file is generated there. Your scale selections and the files you build never leave this page.

Word item numbering

With the instrument's own numbers, the printed number matches the item number in this page's Qualtrics and REDCap exports, so paper responses can be typed in without translating them.

Word item order

A shuffled form is not scored as it stands. Responses collected from it arrive in the order the form prints, which is not the instrument's own item order; put the collected columns back into the original HiTOP-SR order before scoring, or the scale scores come out wrong with no error to warn you.

The Qualtrics and REDCap files are never shuffled — there an item number names a collected data column.

Qualtrics and REDCap naming

These name what the import creates in the target system. They do not appear on the Word form, and they change nothing about the items themselves. Each box starts at the package's own default; empty a box and that default is used.
